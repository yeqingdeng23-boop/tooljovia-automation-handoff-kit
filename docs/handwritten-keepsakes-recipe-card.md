# Turn a handwritten recipe note into a keepsake card

Have a family recipe note you want to keep alongside your own words? [Handwritten Keepsakes](https://tooljovia.com/handwritten-keepsakes/) lets you make a card for free, without an account or email.

No personal image ready? [Try the fictional example](https://tooljovia.com/handwritten-keepsakes/#/how). Choose **Download fictional example** for the JSON, then **Open an editable copy** and select that file. Choose **Check this file first**, then **Open these as new copies** to add it. Existing collections are kept.

![Fictional typeset recipe-card example, not real handwriting.](https://tooljovia.com/handwritten-keepsakes/examples/fictional-recipe.png)

1. Select **Begin a keepsake**, name your collection, choose **A keepsake card** as the printed edition, and create it.
2. Select **Add an original**, give the image a name, choose a photo of the note from your device, and keep the original.
3. Choose **Compose a page**. Select the photo under **First picture**, add your own words, and type any transcription yourself. Save the page.
4. Open **Print & share**, select that page, and prepare the printable edition. Your browser downloads an HTML file you can open and review.

Your collection stays in this browser. Editable copies and backups contain the full original image and are not encrypted; keep them somewhere private. Cropping is not secure redaction. If you share a general workflow question, leave out the original and personal story.
