# Pip and Dot Open the Paper Door

In [Wonderpatch](https://tooljovia.com/wonderpatch/), choose **Open a creation**, select `Pip-and-Dot.wonderpatch.json`, choose **Check this file first**, and then **Open a new copy**. Open each of the two scenes separately to read its lines or use its scene playback controls. Edit the characters and dialogue in your copy.

This is a fictional paper-puppet play featuring Robot Pip and Little star Dot. It contains no real children's information, photographs or recorded voices. The JSON file is the editable project.

Creations are stored in the browser you use. Download and keep a private backup if you want to preserve your changes or move them to another device.

## Read or print first

[Open the one-page activity sheet](Pip-and-Dot-paper-theatre-activity.pdf) to read both scenes aloud, change a line or imagine a new ending. The sheet is one page, US Letter, with space for handwriting; adjust the paper size or scaling in your print dialog as needed.
