# ToolJovia Task Worksheets

Free worksheets for reviewing a client project before delivery. Start with the blank checklist, review the hypothetical example, then use your own authorized project records.

## Start here

1. Open `CLIENT_HANDOFF_CHECKLIST.en.md`. Identify the environment, required checks, operating owners and decision owner.
2. Read `CLIENT_HANDOFF_WORKED_EXAMPLE.en.md`. Matching path records still leave the human signoff unfinished.
3. Use `03-test-record.md` and `04-client-handoff.md` for your actual evidence references and open work.
4. Use the branch and acceptance workbenches if you want help organizing the records. Transfer records manually; there is no automatic project loading.

The files in `sample-exports/` are completed browser exports of the **synthetic** A/B example. A matching record is not a live workflow test. These are not actual client deliverables, approval records or customer outcomes.

## Optional cost review

`01-project-scope.md`, `02-cost-and-exceptions.md` and `SAMPLE_REPORT.md` help separate delivery labor, cash costs and manual capacity. The USD figures are hypothetical, not a market price or observed profit; acquisition, refunds, tax and unentered work remain outside the estimate.

## Example inputs

`sample-inputs.json` contains the A/B fields. `sample-expected.json` contains the independent expected calculations. Use these for the example, not as evidence that a real customer's automation was tested.

## Use with your own records

Keep passwords, API keys, tokens and customer records out of these files and optional feedback. Keep real execution evidence in the project's authorized location. ToolJovia reviews the data you enter; it does not migrate credentials, connect accounts, run live automation, approve a release or make a client accept the work.

Version 0.3. These worksheets and checklist are provided for use and adaptation in your own or client projects. Keep the synthetic example identified as a demonstration. No paid support, implementation or outcome promise is included.
